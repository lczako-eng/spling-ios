Accessibility at Spling

Spling exists because ordinary transactions quietly exclude people communication fails: people with speech differences, deaf and hard-of-hearing people, AAC users, people with aphasia, autistic people, people whose anxiety makes a counter hard, anyone with a temporary injury, and anyone doing this in a language that isn’t the local one. Accessibility is not a feature of this product. It is the product. So this page is not a legal formality; it is the standard we ask you to hold us to.

The standard we target

WCAG 2.2 Level AA, with AAA contrast on body text wherever the palette allows it. That is the floor, not the ambition.

What is implemented today

  • Reduced motion is honoured completely. The home page is authored so its finished, still state is the default; animation is added only when your system says it is welcome, and is removed again immediately if you change that setting mid-visit. With reduced motion on, the page runs zero animations — the particle field is replaced by a plain table saying the same thing.
  • Every animation is narrated. The particle field, both order demos, the drive-through scene and the caregiver exchange each carry a written description for screen readers that says what happens and why it matters. No information exists only in motion.
  • Atkinson Hyperlegible for body text, designed by the Braille Institute for low-vision readers.
  • Full keyboard navigation with visible focus indicators on every interactive element, on both light and dark sections. There is a skip link, and while the opening animation plays there is a second link to skip it.
  • Semantic landmarks and headings, so screen readers can move through the page structurally rather than linearly.
  • The waitlist form has a visible label (never a placeholder standing in for one), announces success and errors through a live region, moves focus to the result, and works without JavaScript.
  • The scrolling language ticker can be paused from the keyboard.
  • No information is conveyed by colour alone. Nothing flashes. Non-English text carries the correct language attributes so screen readers pronounce it properly.

Known gaps

Being specific is more useful than claiming perfection:

  • Body links sit at AA contrast rather than AAA, because the brand colour is fixed. Links are underlined, so colour is never the only signal.
  • Type is loaded from Google Fonts. If that request fails, the page falls back to your system fonts — readable, but not Atkinson Hyperlegible.
  • The site has not yet been through a formal audit with an external testing organisation, or user testing with AAC users. Both are planned before the connector opens publicly, and we would rather say so than imply otherwise.

The product itself

The same standard applies past the website. Spling is used through whichever assistant you already use, in whatever way you already use it: typed, spoken to your own device, or composed on an AAC system. Requests are transmitted as structured data, so nothing about your speech, hearing, or language has to survive a speaker, a noisy room or a queue. Your communication profile is yours: it shapes how the transaction is composed, and it is never shared with the business.

Signed languages are treated as languages. ASL and LSQ are not English, and a Deaf signer handed a notepad at a counter is being asked to write a second language at speed. Spling does not read sign — the language happens between you and your assistant, in whatever form that already works for you — but it never requires English at the counter, and it does not file signing under “accommodation”.

The connector itself is still in build. This page describes what it is being built to do, and we would rather be plain about that than let a website imply something is shipping when it isn’t.

Telling us about a barrier

If any part of this site or product doesn’t work with your screen reader, switch device, magnifier, AAC system, or anything else you use — that’s a bug, and we’d genuinely like to hear about it. Write to hello@spling.org with whatever detail is easy to share; a rough description is plenty, and you never need to file a formal report. A person reads these, and we’ll reply.
